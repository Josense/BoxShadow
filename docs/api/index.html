BoxShadowLayout

com.josense.boxshadow.BoxShadowLayout hosts one child and draws an outer shadow, fill color, optional drawable, inset shadow and border before the child.

shadow: BoxShadow
Outer shadow and shared corners. Blur must be nonnegative. Spread and X/Y offset can be negative. Outer shadow space is reserved during measurement.
innerShadow: InnerShadow?
Inner shadow follows the inside edge of the border. Set to null to disable. A positive spread extends the shadow toward the center.
boxFillColor: Int
ARGB fill beneath the drawable. Defaults to transparent.
boxBackground: Drawable?
Drawable clipped to the card outline.
boxStrokeWidth: Float, boxStrokeColor: Int
Width and ARGB color of the border. Width is reserved between the outer outline and the content.

Kotlin lengths use physical pixels. Use dimension units such as dp in XML. Corners are specified in physical top-left, top-right, bottom-right, bottom-left order.
